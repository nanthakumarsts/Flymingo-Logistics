# Flymingo Logistics - Backend API Server

This directory contains the Express.js backend architecture for Flymingo Logistics.

## Folder Structure:
- `server.js` - Server entry point with CORS, JSON body parser, and API routes
- `routes/` - Express route handlers for sliders, home, about, services, testimonials, inquiries
- `controllers/` - Route controller logic and database queries
- `models/` - Mongoose / Database schemas

## How to Run Backend:
1. `cd server`
2. `npm install`
3. `npm run dev`
